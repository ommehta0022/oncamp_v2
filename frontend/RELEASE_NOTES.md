## OnCampus 1.6.0

- Rebuilt Discover to match the approved blue/white campus reference experience with featured institutions, trending campuses, nearby campuses and recently viewed campuses.
- Rebuilt public institution profiles with Home, Groups, Events, Campus and About tabs.
- Institution Studio content now appears directly in the mobile experience, including campus story metrics, gallery media, announcements, communities, departments, programs, events, opportunities and achievements.
- Added polished event cards with date, media, time, venue, attendance and RSVP controls, plus opportunity cards for internships, placements, workshops, scholarships and competitions.
- Added the shared animated campus loading experience for app startup, Discover, institution profiles and feed loading states.
- Added a recoverable app error boundary and bounded startup settings check so a recoverable JavaScript or temporary network failure does not look like the app immediately closing.
- Updated the mobile visual system and bottom navigation to the approved navy/blue/white style.
- Improved campus loading performance by using existing cache-first reads and parallel public institution bundle requests.
- Moved Android and OTA runtime to 1.6.0 so this APK starts from a clean native/OTA compatibility boundary instead of loading incompatible 1.5 runtime state.
- Keeps Institution-owned publishing rules: students cannot create/share/repost/publish post requests; institution collaboration remains institution-controlled; no 1:1 DM and no voice/video calling.

This is a full native Android release and must be installed as the new 1.6.0 baseline before future 1.6 OTA updates.
